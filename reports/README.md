# Bảng số liệu và hình

Mọi con số trong báo cáo và slide truy được về một file trong thư mục này.

| Thư mục | Nội dung |
|---|---|
| `data/` | nguồn dữ liệu, kiểm chứng, đếm từng bước làm sạch, EDA, cân bằng |
| `asr/` | kết quả hai baseline, đối chiếu paper, phân tầng, audit audio dài, ma trận nhầm dấu, năm giả thuyết Gap Analysis |
| `mt/` | bootstrap từng cặp hệ, phân tích lỗi V1 đến V4 |
| `domain/` | nhãn miền FLoRes+ và kết quả theo miền |
| `toc_do/` | đo RTF, latency, VRAM; ba lần đo xen kẽ cho mỗi hệ |
| `tong_hop/` | bảng ablation, flowchart làm sạch, biểu đồ tổng hợp |
